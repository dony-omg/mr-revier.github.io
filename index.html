Token được lưu trực tiếp vào localStorage mà không encrypt. Dễ bị XSS đánh cắp — nên dùng httpOnly cookie thay thế.
⚠️ Warning src/hooks/useData.ts · line 87

💡 Suggestion src/utils/format.ts · line 15
Hàm này được gọi nhiều lần với cùng input. Có thể dùng useMemo hoặc memoize để tránh tính toán lại không cần thiết.

Cài đặt

Chỉ cần làm 1 lần duy nhất

1

Tạo GitLab Personal Access Token

Vào GitLab → Access Tokens, tạo token với scope api. Copy token (dạng glpat-...).

2

Chạy setup script

macOS / Linux:

bash <(curl -s https://gitlab.kyanon.digital/shiva/tool/mr-reviewer/-/raw/main/setup.sh)

Windows (PowerShell):

powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest https://gitlab.kyanon.digital/shiva/tool/mr-reviewer/-/raw/main/setup.ps1 -OutFile $env:TEMP\setup.ps1; & $env:TEMP\setup.ps1"
3
